# moqom-rust

The Rust backend SDK for [MOQOM](https://moqom.cloud): mint join tokens, manage
rooms, moderate, and follow room events from your server. The crate and its full
README are in [`moqom-sdk/`](moqom-sdk/README.md); documentation is at
[moqom.dev](https://moqom.dev).

The crate is not on crates.io yet; depend on a release tag:

```toml
[dependencies]
moqom-sdk = { git = "https://github.com/moqom-cloud/moqom-rust", tag = "v0.1.0" }
```
